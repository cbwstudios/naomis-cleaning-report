# Naomi's Cleaning Report

Single-page client report for naomiscleaning.com: **Sitemap** tab (every live and planned page) and **Updates** tab (pending queue + dated completed batches).

- Source of truth: `index.html` in this folder (Dropbox: `Naomis Cleaning/Report/`).
- Live URL: https://cbwstudios.github.io/naomis-cleaning-report/
- Publish: double-click `Publish Report.bat`. It commits `index.html` and pushes to GitHub; GitHub Pages redeploys in about a minute.

One-time setup (already done if the bat runs clean): repo `cbwstudios/naomis-cleaning-report`, GitHub Pages source = branch `main`, folder `/ (root)`.
